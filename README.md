# Stackly Portfolio & Creative

A responsive multi-page portfolio and creative studio website adapted from the supplied Procurement Services project while retaining its original page structure and front-end setup.

## Pages
- `index.html` — Home and featured creative positioning
- `about.html` — Studio story, values, and team
- `services.html` — Brand identity, creative direction, digital design, web design, content, and portfolio strategy
- `blog.html` — Creative journal and design insights
- `contact.html` — Contact and project inquiry form
- `signin.html` / `signup.html` — Account access
- `admin-dashboard.html` / `user-dashboard.html` — Dashboard layouts
- `404.html` — Custom not-found page

## Project structure
- `assets/` — Images and visual assets
- `css/style.css` — Main website styles
- `css/dashboard.css` — Admin and user dashboard styles
- `js/script.js` — Navigation, interactions, and marketing-page behavior
- `js/auth.js` — Authentication form interactions and validation
- `js/dashboard.js` — Dashboard interactions

## Run locally
1. Extract the ZIP archive.
2. Open this folder in VS Code.
3. Start `index.html` with Live Server, or open it directly in a browser.

## Notes
This project uses front-end HTML, CSS, and JavaScript. Authentication and dashboard data are demo/front-end interactions unless connected to a backend. Review all images and replace any source-theme photography with portfolio, design studio, branding, or creative-work imagery before production deployment. Update contact details and form handling before publishing.
